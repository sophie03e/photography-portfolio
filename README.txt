PHOTOGRAPHY PORTFOLIO — QUICK START

1. Upload this entire folder to a GitHub repository.
2. Put your photographs inside the images folder.
3. Use the filenames already referenced by the HTML files, OR edit the filenames in the HTML.
4. Replace the project titles, descriptions and About text with your own.
5. On GitHub: Settings → Pages → Deploy from branch → main → / (root).
6. Your free site will then be available at your GitHub Pages address.
